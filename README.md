# Моделирование жидкосцинтилляционного детектора

Сферический детектор: R = 2 м, N = 40, r = 0,10 м.
Световой выход Y = 10 000 фотонов/МэВ, параметр отклика a = 0,5.

## Решения задач

1. [Геометрия детектора](01_detector.ipynb)
2. [Изотропный источник](02_source.ipynb)
3. [Распространение и детектирование света](03_light_detection.ipynb)
4. [Распределения заряда](04_charge_distributions.ipynb)

Общий код расположен в `detector.py`, `source.py`, `light_simulation.py`
и `charge_study.py`.

## Запуск

```bash
pip install -r requirements.txt
jupyter lab
```

Открывайте ноутбуки из корня проекта. Каждый ноутбук запускается независимо
от остальных. Четвертый ноутбук выполняет полный расчет серий.
Для интерактивного метода `Detector.visualize()` дополнительно нужен `k3d`;
встроенные в ноутбуки графики работают без него.

## Явные соглашения модели

- Энергия задается в МэВ; длины — в метрах; заряд — в фотоэлектронах.
- M = round(YE) фиксировано; излучение изотропное.
- Нет рассеяния и поглощения в объеме. На границе фотон поглощается.
- Фотокатод аппроксимирован сферической чувствительной областью с радиусом
  r по хорде. Это приближение к плоской площадке при r/R = 0,05, а не
  точное пересечение луча с плоским кругом.
- В соответствии с отдельным условием задачи 3 отклик на попавший фотон
  равен Poisson(a), то есть a — среднее. В общей концепции проекта a назван
  вероятностью хотя бы одного фотоэлектрона. Для Пуассона P(k>=1)=1-exp(-a).
  Если вероятность равна 0,5, соответствующее среднее равно ln(2).
  Представленные расчеты используют прямое условие задачи 3: среднее 0,5.
- Для центрального источника вероятность попадания p = Nr²/(4R²).
  Множитель 1/4 следует из площади сферы 4πR².

В `charge_results` сохранены результаты всех событий, сводная таблица
и графики. В `figures` — иллюстрации первых трех задач.
